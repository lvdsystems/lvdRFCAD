lvd RF cad

Electrical CAD for RF engineer, antenna design and SPICE simulation

3 different document types:
- RF editor allows placing all RF components like attenuators, amplifiers mixers ecc...
  - S paramers editor
  - ability to define new symbols to make library for new components (like a specifc lna from analog devices)
  - big default library
- SPICE simulator
  - embedded kernel
  - like tinaTI simulator feature but modern editor
  - huge default library
  - subschematic support
  - custom symbol and code
- Antenna design
  - antenna and groups of antenna for beamforming
  - radiation pattern simulation
  - AESA antenna designer

  QT6 application
